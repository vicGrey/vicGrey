### 🚀 Featured Project: Zero Trust Serverless Governance
**[View Repository Here](https://github.com/vicGrey/aws-serverless-zero-trust-governance)**

I designed and implemented a proactive, three-layer Zero Trust governance framework to secure serverless financial applications against misconfigurations and Denial of Wallet (DoW) attacks. 

*   **Pre-Deployment:** Engineered a GitHub Actions CI/CD pipeline integrated with Open Policy Agent (OPA) and Conftest to evaluate Terraform execution plans. Automatically blocks unauthenticated APIs, over-privileged IAM roles, and exposed S3 buckets before they reach production.
*   **Runtime Enforcement:** Utilized Amazon API Gateway and Cognito for JWT-based per-request identity verification.
*   **Continuous Compliance:** Deployed AWS Config managed rules for continuous runtime detection of out-of-band configuration drift.
